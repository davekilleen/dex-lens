# Dex Lens risk register

Last updated: 2026-08-21

This is the lightweight register for risks that must stay visible until the
full R7 handoff pack exists. Every unresolved entry needs a named owner before
pilot sign-off.

| ID | Risk | Evidence | Impact | Current mitigation | Owner | Status |
| --- | --- | --- | --- | --- | --- | --- |
| RISK-MAC-SOCKET-CREATION | macOS Seatbelt blocks outbound connection, not socket creation, on GitHub macos-14 runners and on local Apple Silicon Macs. | CI runs 31244515811, 31244792823, and 31244920768 showed AF_INET, AF_INET6, and AF_UNIX sockets were created under the shipped profile despite `(deny system-socket)`, while the runtime proof returned `connect-denied`, `write-open-denied`, and `exec-denied`. Reproduced locally on macOS 26 / Apple Silicon on 2026-08-21. | The macOS containment story is asymmetric with Linux: no egress is enforced, but "no socket fd can exist" is not proven on the pilot platform. | **Accepted asymmetry (2026-08-21).** `MacOSStrategy.availability()` requires a fresh runtime tuple proving no-write, no-exec, and no-network, where the no-network proof is satisfied by either `socket-denied` or `connect-denied`. Egress needs `connect`/`sendto`, and `prove_containment` aborts the collection if a connection succeeds or fails ambiguously, so the guarantee the product makes to a person — nothing leaves this machine — is proven either way. The honest label is carried through to `ContainmentOutcome.proofs` and shown verbatim, never relabelled as `socket-denied`. Keep `(deny system-socket)` plus `(deny network*)` and retain the direct egress probe. | Dave | Closed — accepted |
| RISK-MAC-INTERPRETER-LITERAL | The Seatbelt exec allowlist named an unresolved interpreter path, so the contained child was denied on any Mac whose Python is symlinked. | Homebrew's `sys.base_prefix` is `/opt/homebrew/opt/python@3.X/...`, a symlink into `/opt/homebrew/Cellar/...`. Seatbelt canonicalises the exec target before matching a `literal`, so the child died in `posix_spawn` and was reported as "containment could not be established". Found on 2026-08-21 during the first real-machine run against a live vault. | Every Homebrew-Python Mac — the common case — silently lost the deep adapter and fell back to the guided path, which reads nothing. Combined with RISK-MAC-SOCKET-CREATION this meant no Mac could ever run a Verified diagnosis. | `macos_profile_params()` resolves the framework launcher before enumerating it, and `test_g1_every_exec_literal_has_its_canonical_form_enumerated` fails if any supplied literal resolves to a path no literal enumerates. | Dave | Closed — fixed |
