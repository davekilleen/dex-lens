# M6 Pilot Evidence Tooling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the fail-closed pilot protocol, measurement, analysis, drill, red-team, and R7 completeness tooling, leaving only real participants and independent approvals external.

**Architecture:** Protocols and per-contract measurement plans are canonical, hash-stamped, and locked before first data. Analysis reports contract-specific evidence only and treats missing data as non-success and any severe trust failure as a stop. A machine-checkable manifest binds synthetic hostile-suite evidence, five exercised runbooks, risk ownership, observed pilot evidence, and signoff.

**Tech Stack:** Python, Pydantic, JSON canonicalization/hashing, pytest synthetic datasets, existing R2/G2 models and gate suites.
