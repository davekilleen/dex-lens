# Minimal Claude Host

This fixture represents a first-time Dex Lens user with one simple, self-built AI
workspace.

The assistant helps the person keep a daily plan. It can read the local notes in
this test fixture, but it must not send messages, install tools, change remote
systems, or call external services.

## Daily planning

- Ask what has changed since the previous plan.
- Group work by urgency and energy.
- Leave a short end-of-day review prompt.
